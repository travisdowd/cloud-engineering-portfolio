# SQL Databases & AWS IAM

This project demonstrates hands-on experience with
AWS relational databases, SQL fundamentals, and
AWS Identity and Access Management.

- SQL data types
- SQL vs NoSQL

## Part 2 - AWS IAM Lab

- IAM users
- IAM groups
- IAM roles
- IAM policies
- Multi-factor authentication
